# Broca's Area Superficial White Matter and Language

This repository contains the R code used for the analyses reported in the manuscript:

**The superficial white matter in language processing: Broca’s area connections are bilaterally associated with individual performance in children and adults**

In this preregistered study, we characterized the anatomy, lateralization, and language associations of Broca’s area superficial white matter (SWM) in early adolescents and young adults using two large, publicly available datasets: the Adolescent Brain Cognitive Development Study and the Human Connectome Project Young Adult Study, totaling over 10,000 participants.

## Contents

* `analysis.R` — R code used for statistical analyses and visualizations.

## Data

The data used in this project are from the Adolescent and Cognitive Development Study (ABCD) dataset, accessible via the National Institute of Mental Health Data Archive (NDA) at nda.nih.gov/abcd, and the Human Connectome Project Young Adult (HCP-YA) dataset, available through the ConnectomeDB at db.humanconnectome.org.

## Software

Analyses were conducted in R. Required packages are specified in the analysis script.
